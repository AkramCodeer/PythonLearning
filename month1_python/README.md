## 🚀 How to Use

### 1. Setup
```bash
# Make sure Python 3.10+ is installed
python --version

# Create a virtual environment
python -m venv venv

# Activate (Windows PowerShell)
.\venv\Scripts\Activate.ps1

# You're ready!
```

### 2. Study Each Module
```bash
# Run each module to see the output
python 01_variables_and_datatypes.py

# Read the code, understand the JS parallels
# Try modifying examples
# Complete the practice exercises at the bottom
```

### 3. Practice Problems
```bash
# Open practice_problems.py and start solving!
# Each problem has a function stub — fill in the code

# Check your answers
python practice_solutions.py
```

### 4. Interview Prep
```bash
# Review the cheatsheet before interviews
python interview_cheatsheet.py
```
