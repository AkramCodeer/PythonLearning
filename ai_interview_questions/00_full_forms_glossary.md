# Full Forms Glossary

| Short form | Complete form | Meaning in this handbook |
| --- | --- | --- |
| AI | Artificial Intelligence | Systems that perform tasks associated with human intelligence. |
| LLM | Large Language Model | A model that generates or understands language. |
| RNN | Recurrent Neural Network | A sequential neural-network architecture for sequences. |
| RAG | Retrieval-Augmented Generation | Retrieve evidence, then generate an answer from it. |
| DB | Database | Organized store of data. |
| ANN | Approximate Nearest Neighbor | Fast approximate similarity search over vectors. |
| HNSW | Hierarchical Navigable Small World | A graph-based ANN index. |
| IVFFlat | Inverted File Flat | A partition-based ANN index supported by pgvector. |
| HyDE | Hypothetical Document Embeddings | Retrieval technique using an LLM-generated hypothetical document. |
| MCP | Model Context Protocol | Protocol for connecting AI applications to tools and resources. |
| A2A | Agent2Agent Protocol | Protocol for communication between AI agents. |
| API | Application Programming Interface | Contract that lets software systems communicate. |
| REST | Representational State Transfer | Resource-oriented HTTP API design style. |
| HTTP | Hypertext Transfer Protocol | Web communication protocol. |
| JSON | JavaScript Object Notation | Text format for structured data exchange. |
| SQL | Structured Query Language | Language for querying relational databases. |
| PII | Personally Identifiable Information | Data that can identify a person. |
| RLHF | Reinforcement Learning from Human Feedback | Alignment method using human preference feedback. |
| NER | Named Entity Recognition | Finds entities such as people, organizations, or locations in text. |
| CRM | Customer Relationship Management | System for managing customer interactions and data. |
| SaaS | Software as a Service | Cloud software accessed as a service. |
| SKU | Stock Keeping Unit | Unique code used to identify an inventory item. |
| FAQ | Frequently Asked Questions | Common questions and answers. |
| HLD | High-Level Design | System architecture view before low-level implementation. |
| I/O | Input / Output | Communication with external services, files, or networks. |
| OpenAPI | OpenAPI Specification | Standard for describing HTTP APIs. |
| BM25 | Best Matching 25 | A common keyword-ranking algorithm. |
